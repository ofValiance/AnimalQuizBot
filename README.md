# LotteryApp

## Описание

Telegram-бот «Кто твое тотемное животное?» — это развлекательная викторина, 
разработанная для Московского зоопарка с целью популяризации программы опеки над животными. 
Пользователь проходит тест из нескольких вопросов о своих предпочтениях (любимые жанры кино, музыка, вид отдыха и т. д.), 
а в конце получает персонализированный результат — одно из животных зоопарка, которое подходит ему по характеру, 
с описанием и информацией о том, как стать его опекуном. Результатом можно поделиться в социальных сетях (Telegram, VK, WhatsApp), 
а также оставить отзыв. Вопросы и список животных гибко настраиваются через JSON-файлы без изменения кода.

## Пользовательский сценарий

Пользователь может:

- Запустить бота командой /start
- Проходить тест, последовательно выбирая ответы на отправленные ботом вопросы
- По завершению теста увидеть результат с информацией о программе опеки и выбранном животном, а так же его фото
- По ссылке перейти на страницу программы опеки
- Поделиться результатом и ссылкой на бота в Telegram, VK и WhatsApp
- Оставить отзыв с оценкой и комментарием
- Перепройти тест

## Установка

1) Установить и открыть Docker Desktop
2) Клонировать репозиторий
3) В Telegram создать нового бота с помощью @BotFather
4) Переименовать файл .env.example в .env и вставить в него токен бота и его название
5) Для запуска использовать скрипты launch.bat (Windows) или launch.sh (Linux, Git Bash)

## Использование

Кроме заимодействия с ботом согласно пользовательскому сценарию возможна настройка теста через файлы в папке resources.

### Редактирование теста

В quiz.json лежит список вопросов. Их можно изменять/добавлять, не меняя при этом сами поля.

### Редактирование списка животных

В animals.json лежит список животных, участвующих в тесте. Их так же можно изменять/добавлять, не меняя при этом сами поля.

### Просмотр отзывов пользователей

В reviews.json можно увидеть сохраненные отзывы пользователей, прошедших тест.
